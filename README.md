## 📁 Standardized Project Directory Structure

Every project folder (`project_01` to `project_55`) strictly follows this uniform architecture:

```
project_XX_<descriptive_name>/
├── docs/
│   ├── technical_documentation.docx    # Comprehensive technical implementation document
│   ├── Project_XX_Abstract.pdf         # Academic abstract (where available)
│   └── Project_XX_Documentation.pdf    # Extended architecture documentation (where available)
├── presentations/
│   └── project_presentation.pptx       # Professional 8-slide presentation deck
├── source_code/                        # All application source code
│   ├── backend/                        # REST API service (FastAPI / Flask / Express)
│   ├── frontend/                       # Web interface (HTML/JS / React / Streamlit)
│   ├── ml_pipeline/ or models/         # Trained model weights, training scripts, pipelines
│   └── data/                           # Datasets, synthetic generators, SQLite databases
├── README.md                           # Project overview, abstract, architecture, and run instructions
└── requirements.txt                    # Top-level dependencies for environment setup
```

## 🚀 Running Any Project

### 1. Prerequisites
Ensure Python 3.10+ is installed:
```bash
python3 --version
```

### 2. Quick Setup & Launch
Navigate into any project directory:
```bash
cd project_XX_<name>
pip install -r requirements.txt
```

Launch the backend service:
```bash
python source_code/backend/main.py
```
*(Or `python source_code/app.py` / `python source_code/run_system.py` depending on the project stack).*

Open the frontend portal:
- View `source_code/frontend/index.html` directly in your browser, or visit `http://localhost:<PORT>`.
- Access generated technical documentation in `docs/technical_documentation.docx`.
- Access the presentation slide deck in `presentations/project_presentation.pptx`.
