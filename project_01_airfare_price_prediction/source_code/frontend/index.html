LSTM Architecture Topology:

  • Input Representation: 31 dimensional standardized and one-hot encoded temporal & carrier feature vector, partitioned across 4 sequential timesteps.
  • Recurrent Backbone: 2-layer Bidirectional LSTM with hidden dimension = 64 (bidirectional representation = 128 hidden units).
  • Dense Projection Head: Linear(128 → 64) → ReLU → Dropout(0.2) → Linear(64 → 1).
  • Loss Function: SmoothL1Loss (Huber Loss) with AdamW optimizer and ReduceLROnPlateau learning rate scheduling.
