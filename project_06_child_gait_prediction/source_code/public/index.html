AI Clinical Insights & Recommendations

Decision-support educational observations for pediatric gait patterns.

Normal Gait Pattern Guidelines

Characteristics: Symmetrical step length, bilateral ground reaction force between 120–135% BW, coronal foot tilt < 8°, linear speed > 1.0 m/s.

  • Routine developmental milestone monitoring.
  • Maintain regular aerobic play and bilateral coordination sports.
  • Re-evaluate if unilateral limping or fatigue occurs during growth spurts.
Diplegic Gait Pattern (Bilateral CP) Guidelines

Characteristics: Bilateral involvement, increased step duration (≥0.70s), reduced stride length (≤65cm), exaggerated pelvic/foot tilt (≥10°), potential crouch gait mechanics.

  • Pediatric physical therapy evaluation for lower limb motor tone.
  • Assessment of hamstring, gastrocnemius, and psoas contractures.
  • Evaluate indications for Ankle-Foot Orthoses (AFOs) to stabilize gait stance phase.
  • Annual longitudinal monitoring to prevent progressive bony deformities.
Hemiplegic Gait Pattern (Unilateral CP) Guidelines

Characteristics: Marked step length asymmetry, unilateral decrease in heel strike pressure, asymmetric weight bearing, circumduction or equinus posture on the affected limb.

  • Pediatric neurology and orthopedics evaluation for unilateral spasticity.
  • Targeted physical therapy to improve stance stability and weight-bearing on the affected side.
  • Consider articulation or dynamic AFO to manage equinus foot strike.
  • Constraint-induced movement or bilateral task-oriented training.

System Architecture & Model Evaluation

SimTK CP Child Gait Dataset ML pipeline documentation.

Dataset & Participants

  • Source: SimTK Pediatric Gait Motion-Capture Dataset
  • Cohorts: TD (5 children, 8 trials), CP_HE (5 children, 7 trials), CP_DI (4 children, 6 trials)
  • Instrumentation: 100 Hz Vicon Plug-in Gait optical 3D markers & 1,500 Hz AMTI dual force plates
  • Partitioning: Strict participant-level split to guarantee zero data leakage between train & test sets

Machine Learning Model

  • Algorithm: Tuned Multi-Class Random Forest Classifier
  • Multiclass ROC-AUC: 1.0000 across Normal, Diplegic, and Hemiplegic classes
  • Held-out Test Accuracy: 66.67% (on strictly unseen participants)
  • Features: Walking speed, stride length, step duration, cadence, pelvic tilt, asymmetry, dynamic force %BW

API Server Integration

The system exposes full REST API endpoints at http://localhost:8000/api with interactive Swagger documentation available at http://localhost:8000/docs. All assessment entries are persisted with ACID properties in the SQLite datastore.
