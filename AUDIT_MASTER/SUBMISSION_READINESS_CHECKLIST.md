## 1. Submission Gate Criteria & Readiness Scoring

Each project is evaluated out of **100 Readiness Points**:
- **Source Code Integrity & Architecture (25 pts)**: Complete backend, frontend, and clean entrypoints.
- **Machine Learning & Model Weights (20 pts)**: Serialized weights, feature encoders, inference pipeline.
- **Datasets & Persistent Storage (10 pts)**: Datasets, schemas, SQLite/PostgreSQL storage.
- **Automated Tests & Verification (15 pts)**: Unit tests, ML pipeline tests, and pass logs.
- **Technical Documentation DOCX (10 pts)**: Executive abstract, system architecture, setup steps.
- **Project Presentation PPTX (5 pts)**: Problem background, methodology, benchmarks.
- **Walkthrough Scripts & Timestamps (5 pts)**: Step-by-step narration script with timestamp intervals.
- **Recorded Walkthrough Video (10 pts)**: Valid playable MP4 video demonstrating the running system.
