## 3. Critical & High-Severity Defects Remediated

During the systematic audit, 6 high-severity defects were uncovered through execution and resolved:

1. **PROJECT-003 (Apple Disease Detection)**: Resolved PyTorch Hub MobileNetV2 SSL certificate validation failure on macOS Python 3.12 by anchoring the SSL default context to the `certifi` CA bundle.
2. **PROJECT-004 (Car Price Prediction)**: Fixed path resolution failure in model training pipeline by converting relative dataset paths to dynamic directory-relative paths.
3. **PROJECT-005 (Career Guidance App)**: Installed missing `xgboost` package required for multi-class job role classification.
4. **PROJECT-007 (Crop Yield Prediction)**: Installed missing `flask_cors` and `pytest` packages to enable automated API testing.
5. **PROJECT-018 (Skin Tone Dress Recommender)**: Fixed catalogue column discrepancies (`outfit_id` vs `item_id`) and enhanced pipeline loading to support both standalone pipelines and dictionary-wrapped estimators.
6. **PROJECT-038 (Pavement Crack Detection)**: Installed missing `sqlalchemy>=2.0.0` for modular FastAPI SQLite persistence.
