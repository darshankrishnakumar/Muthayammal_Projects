💡 Why GNNs Outperform Traditional SQL Rules:

Rule-based AML triggers only look at individual transfers (e.g. > $10,000). Organized criminal syndicates evade this using smurfing (micro-splits) and multi-hop carousels where no single transfer looks anomalous. Graph Neural Networks propagate embeddings across paths, enabling immediate detection of cyclic and tree-structured flow anomalies regardless of dollar amounts.

🧠 2-Layer Graph Convolution Architecture
This system executes 2 rounds of neighborhood feature aggregation:
Layer 1: Local Neighborhood Aggregation
hv(1) = ReLU( W1 · ∑u ∈ N(v) hu / √(dv · du) )
Aggregates account balances, in/out velocity, and channel mix of direct neighbors.
Layer 2: Multi-Hop Topology Pooling (GraphSAGE)
hv(2) = Softmax( W2 · MaxPool({ hu(1), ∀ u ∈ N(v) }) )
Captures 2-hop structural patterns (e.g., circular paths, funnel aggregators).
Classification Head: Fraud Probability
P(Mule | v) = σ( Wout · hv(2) )
