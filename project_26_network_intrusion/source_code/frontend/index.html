🔬 Autoencoder Reconstruction Loss Metric

Supervised machine learning algorithms (like Random Forest) can only recognize known, previously trained attack signatures. To catch Zero-Day exploits, this system uses an unsupervised Autoencoder that reconstructs benign network flow distributions. When an unknown exploit arrives, the reconstruction loss spikes past the tolerance threshold (τ = 0.0450).

Autoencoder Loss Function:
L(x, x̂) = || x - Decode(Encode(x)) ||²
Zero-Day Flag Trigger: L(x, x̂) > 0.0450
