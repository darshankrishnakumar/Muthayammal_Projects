    PyTorch 2.x Deep Learning Engine

    Formal specification of character-level CNN, word embedding, bidirectional LSTM context fusion, and attention pooling layers.

    LEVEL 1: CHARACTER 1D-CNN

    Character-Level Subword Encoding

    Captures typographical spoofing, letter substitution, and domain variations (e.g. micros0ft, chase-secure-verify.com) using 1D convolutional kernels over character indices.

    char_conv = Conv1d(in=32, out=32, k=3, p=1) + MaxPool1d(2)
    LEVEL 2: WORD EMBEDDING

    Semantic Sequence Representation

    Maps clean token vocabulary to a 64-dimensional semantic manifold, preserving syntactic meaning and lexical associations across natural language email bodies.

    word_embed = Embedding(vocab_size=10000, dim=64, pad=0)
    LEVEL 3: BIDIRECTIONAL LSTM

    Left & Right Contextual Modeling

    A dual-direction recurrent LSTM layer processes concatenated multilevel vectors, modeling surrounding linguistic context on both sides of every token.

    bilstm = LSTM(in=96, hidden=64, bidirectional=True)
    LEVEL 4: SELF-ATTENTION LAYER

    Phishing Focus Weighting (α)

    Computes soft scalar attention weights across words and character sequences, focusing classification gradients on deceptive urgency words and suspicious links.

    α_i = softmax(v^T * tanh(W * h_i + b))
    LEVEL 5: HEADER VECTOR FUSION

    SPF/DKIM & Envelope Verification

    Concatenates 8 structural header features (From vs Reply-To mismatch, SPF pass/fail, DKIM cryptographic signature, urgent markers) into the dense classification layer.

    dense_head = Linear(hidden_dim + 8, 32) -> Dropout(0.4) -> Linear(32, 1)
    LEVEL 6: UNBALANCED CALIBRATION

    Focal Loss & Traffic Skew Invariance

    Trained to retain 99.55% legitimate emails while detecting 99.2% phishing attacks under realistic traffic environments where attacks represent less than 1% of total email volume.

    L_focal = - α_t * (1 - p_t)^γ * log(p_t)
