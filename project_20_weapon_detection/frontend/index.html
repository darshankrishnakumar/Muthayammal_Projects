🏗️ YOLOv8 Neural Network Architecture Pipeline
225 Layers // 3,011,048 Parameters // Anchor-Free Head

1. Feature Backbone (CSPDarknet53)

Extracts rich multi-scale spatial representations. Employs C2f (Cross Stage Partial with 2 Convolutions) modules and SPPF (Spatial Pyramid Pooling - Fast) to capture fine-grained contours of concealed firearms and bladed edges.

2. Feature Aggregation Neck (PAN-FPN)

Combines bottom-up path augmentation with top-down feature pyramids. Merges semantic context with low-level spatial textures to preserve weapon detection fidelity across small, medium, and large target scales.

3. Decoupled Detection Head

Separates object classification (Binary Cross-Entropy Loss) from bounding-box regression (CIoU + Distribution Focal Loss). Employs Anchor-Free prediction with Task-Aligned Assigner for millisecond-level inference.

Project 20: Weapon Detection Using Machine Learning YOLOv8

Domain: Computer Vision & Public Security • Module: project_20_weapon_detection • Architecture: Deep Convolutional Neural Network (YOLOv8) + OpenCV Acceleration

📄 Official Project Abstract

Weapon detection using machine learning, specifically through the use of YOLOv8 (You Only Look Once version 8), aims to enhance security systems by automatically identifying weapons in real-time from images. YOLOv8, a state-of-the-art object detection algorithm, leverages deep learning techniques to detect and classify objects with high accuracy and efficiency. By training on large datasets of weapon images, YOLOv8 can identify various types of weapons, such as guns, knives, and explosives, even in complex and crowded environments. This automated detection system can significantly improve public safety by quickly identifying potential threats and enabling faster response times.

⚙️ Mathematical Objective Function & Loss Formulations

YOLOv8 eliminates predefined anchor priors and utilizes a Task-Aligned Assigner to optimize an anchor-free loss function composed of classification and bounding-box regression components: 

Loss_total = λ_cls * L_BCE + λ_box * L_CIoU + λ_dfl * L_DFL

Where:
  • L_BCE: Variational Binary Cross-Entropy classification loss across weapon classes.
  • L_CIoU: Complete Intersection-over-Union loss taking overlap area, aspect ratio, and centroid distances into account:
            CIoU = 1 - IoU + (ρ²(b, b_gt) / c²) + α * v
  • L_DFL: Distribution Focal Loss modeling continuous bounding-box distribution offsets near true target edges.
