🔌 FastAPI REST Service Specification

Production OpenAPI REST endpoints available on http://localhost:5004.

GET/api/health

Returns system operational health, models in memory, and artifact availability.

GET/api/presets

Provides curated vehicle specifications for instant interactive evaluation and testing.

POST/api/predict

Executes regression inference pipeline, computes 90% confidence bounds, and logs transaction.

GET/api/info

Returns complete model metrics, feature importances, and brand catalog metadata.

GET/api/history

Retrieves paginated SQLite valuation records.

GET/api/analytics

Returns aggregated valuation statistics, average resale prices, and retention distributions.

GET/api/dataset/sample

Returns raw benchmark vehicle sample rows from the CSV repository.
